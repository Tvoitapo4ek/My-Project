# Свои текстуры, модели и анимации

## Текстуры — прямо в игре

**Esc → «Текстуры».** Слева все текстуры игры, в центре холст 32 × 32,
справа цвет, палитра, инструменты и превью 3 × 3 (видно швы при повторе).

| Действие | Как |
|---|---|
| Кисть / заливка / пипетка / ластик | `B` / `F` / `I` / `X` или кнопки |
| Взять цвет с холста | ПКМ |
| Темнее / светлее | `[` / `]` |
| Отменить | `Ctrl+Z` (64 шага) |
| Сохранить | `Ctrl+S` → `assets/textures/<имя>.png` |
| Сброс | вернуть файл с диска (можно отменить) |

Каждый мазок сразу виден на блоках и моделях вокруг — мир за окном
обновляется вживую. Точка `•` после имени — есть несохранённые правки.
Палитра: 16 цветов стиля (сталь, латунь, медь, дерево, резина, свечение)
и самые частые цвета самой текстуры. Иконки в инвентаре обновятся после
перезапуска.

Можно рисовать и во внешнем редакторе (Aseprite, LibreSprite, Piskel):
PNG 32 × 32 в `assets/textures/`.

## Модели — Blockbench

[Blockbench](https://www.blockbench.net) (бесплатный) — редактор блочных
моделей, тот же подход, что у игры: модель = набор брусков.

1. Взять готовую модель за основу: в консоли (`T`)
   `model export gearbox` (ключ блока) или `model export player`.
   Файл появится в `assets/models/<ключ>.bbmodel`.
2. Открыть его в Blockbench (File → Open Model), править.
3. Сохранить (`Ctrl+S`) туда же и перезапустить игру.

Модель из `assets/models/<ключ>.bbmodel` заменяет встроенную везде: в мире,
в руке, на иконке, в «Как работает». Удалить файл — вернётся встроенная.

**Правила файла**

* Формат «Generic Model». 16 пикселей Blockbench = 1 блок; блок занимает
  X/Z −8..8, Y 0..16. Формат «Java Block» (0..16) тоже понимается.
* Материал бруска — по имени его текстуры: `brass.png` → латунь. Годится
  любая текстура из `assets/textures` и цвета стиля (`glow_amber`,
  `glow_cyan`, `screen`…). Без текстуры — сталь. UV граней не
  используются: каждая грань показывает всю текстуру, как у встроенных
  моделей.
* Вращение брусков и групп — любое.
* **Что движется — по имени группы:**

| Группа | Движение |
|---|---|
| `rotor` | крутится со скоростью вала вокруг оси блока (Y) |
| `rotor_x`, `rotor_z` | вокруг X / Z (боковые шестерни, выход двигателя) |
| `port0`…`port5` | выход коробки передач в сторону `0..5` |
| `steer` | поворачивается рулём (подвеска) |
| `mount` | следует за подшипником / поршнем |
| `pole` | шток поршня, растягивается по Y |
| остальное | неподвижный корпус |

Коллизия блока не меняется — это всегда куб (или его форма).

**Игрок** — `assets/models/player.bbmodel`, рост 32 пикселя. Группы по
имени вешаются на кости, которые анимирует игра: `head`, `body`, `arm…`,
`leg…` (правая/левая — по знаку X: правая на +X). Шлем, шляпа, рюкзак —
просто бруски в группе `head` или `body`; ходьба, бег, присед и взмах руки
продолжают работать.

## Анимации — план

Сейчас анимации процедурные: вращение роторов, руль, ходьба и присед
игрока. Следующий шаг — анимации из Blockbench (вкладка Animate), из того же
`.bbmodel`:

* **игрок**: анимации с именами `idle`, `walk`, `run`, `crouch`, `swing`,
  `swim` заменят встроенные (ключевые кадры поворота/сдвига костей,
  плавный переход между ними);
* **механизмы**: анимация `work` проигрывается со скоростью, пропорциональной
  оборотам (поршни, шатуны, клапаны дизеля); `on` / `off` — для дверей,
  ламп, рычагов.

Формат файла уже подходит — понадобится только чтение ключевых кадров.
