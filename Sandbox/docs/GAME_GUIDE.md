# Sandbox — полное описание игры

Документ описывает всё, что сейчас есть в игре:
1. что это за игра;
2. управление;
3. все блоки и предметы;
4. механики;
5. визуальный стиль;
6. как игра устроена «под капотом» — простыми словами;
7. документация для разработки: модули, данные, как добавлять новое, тесты.

Числа и состав взяты из текущего кода и данных (`assets/content/*.ron`, `src/`).

## 1. Что это за игра

**Sandbox** — воксельная (блочная) физическая песочница в духе Garry's Mod,
Minecraft и Hytale. Написана на Rust, движок Bevy 0.20, физика Avian 0.8.

Сейчас есть только **творческий режим**:
- строить из блоков;
- собирать механизмы, как в моде Create: моторы, валы, шестерни, коробки передач;
- управлять механизмами с пульта, сидя на сиденье;
- склеивать постройки и превращать их в физические тела — например, в машину, которая едет;
- двигать физические объекты гравитационной и физической пушками;
- выводить скорость и обороты на механические экраны прямо на машине;
- включать фары, копировать постройки чертежом и сохранять их по имени;
- проверять машины на инженерном полигоне;
- строить поворотные платформы и краны на подшипниках, выдвигать части поршнями;
- проводить жидкости по трубам, заливать дизель и запускать дизельный двигатель;
- спускать на воду плоты и подлодки с балластными цистернами;
- собирать схемы из проводов, кнопок, рычагов, таймеров и логических элементов;
- передавать вращение цепями и механическими лентами, строить гусеничную технику;
- строить из плит, ступенек, скосов и угловых скосов любого материала,
  ставить раздвижные двери, смотреть характеристики блоков в инженерных очках.

Игра начинается с **главного меню** («Играть», «Настройки», «Выход»); Esc в
игре ставит её на паузу (см. 4.17).

**Мир** — инженерный полигон 128 × 128 блоков, висящий в пустоте:
- пол из тёмного бетона, светлые линии разметки по границам чанков
  (каждые 16 блоков);
- на западном краю — испытательная зона из пяти дорожек (см. 4.11);
- на восточной стороне — испытательный бассейн 32 × 32 глубиной 10 блоков
  со спуском 25° для машин (см. 4.15);
- синее небо;
- смена дня и ночи, сутки длятся 20 реальных минут;
- игра начинается в 10:00;
- кто упал с платформы ниже 60 м, возвращается на точку появления.

**Стартовый хотбар**: белый блок, камень, доски, стальная рама, стекло,
гаечный ключ, клей, гравитационная пушка, физическая пушка. Всё остальное
берётся из каталога (E → «Все предметы»).

## 2. Управление

### Передвижение

| Клавиша | Действие |
|---|---|
| W A S D | ходьба |
| Мышь | взгляд |
| Ctrl (с W) | бег |
| Shift | присесть: так нельзя упасть с края блока, сколько ни идти |
| Пробел | прыжок |
| Пробел дважды быстро | полёт вкл/выкл |
| В полёте: Пробел / Shift | вверх / вниз; Ctrl — вдвое быстрее |
| F5 | вид: от первого лица → сзади → спереди |

| Движение | Скорость |
|---|---|
| Ходьба | 4,3 м/с |
| Бег | 5,6 м/с |
| Присед | 1,3 м/с |
| Полёт | 10,9 м/с, с Ctrl — 21,8 м/с |
| Прыжок | около 1,3 блока в высоту |

Если в полёте приземлиться с зажатым Shift, полёт выключается.

### Блоки

| Кнопка | Действие |
|---|---|
| ЛКМ | сломать блок (удерживание — ломать подряд) |
| ПКМ | поставить блок из руки на грань, в которую смотришь (удерживание — ставить подряд) |
| ПКМ по сиденью | сесть |
| ПКМ по переключателю физики | включить или выключить физику |
| Shift + ПКМ по сиденью или переключателю | поставить на него блок, а не использовать |
| СКМ (колесо) | взять блок, на который смотришь, в хотбар |
| 1–9, колесо мыши | выбрать слот хотбара |

Дальность действия — 8 блоков. Блок под прицелом обведён тонкой рамкой.

### Окна

| Клавиша | Окно |
|---|---|
| E | инвентарь; внутри кнопка «Все предметы» — каталог и обратно |
| F3 | меню отладки |
| T или / | консоль |
| Esc | в игре — пауза; в окне — закрыть его |
| Esc → «Текстуры» | редактор текстур (`docs/MODDING.md`) |

**Подсказки в инвентаре.** Наведите мышь на предмет — коротко, что это.
С Shift — подробно. Удерживайте W над механизмом — «Как работает»:
маленькая сцена, которая собирается по шагам (каждые 6 с; ← → или колесо —
листать, Esc — назад в инвентарь).

Клавиши движения, прыжка, приседания, бега, инвентаря и вида камеры
переназначаются в «Настройки → Управление».

## 3. Предметы и блоки

Каждый блок — это одновременно предмет с тем же ключом. Блоки складываются
в стопки по 64, инструменты по 1.

### 3.1 Строительные блоки (категория «Строительные»)

Обычные кубы. Ничего не делают сами, служат для стройки и как кузов машин.
Масса учитывается, когда блок становится физическим.

| Блок | Ключ | Масса | Особенности |
|---|---|---|---|
| Белый блок | `white_block` | 100 кг | из него сделана платформа мира |
| Камень | `stone` | 150 кг | |
| Доски | `planks` | 40 кг | тёмное дерево — лёгкий материал |
| Стальной блок | `steel_block` | 200 кг | клёпаные стальные плиты, тяжёлый |
| Стальная рама | `steel_frame` | 60 кг | открытая рама, видно насквозь; соседние блоки за ней не скрываются |
| Стальной корпус | `steel_casing` | 120 кг | сталь с болтами и деревянной вставкой (как корпуса Create) |
| Стекло | `glass` | 30 кг | прозрачное, у соседнего стекла нет внутренних граней |
| Бетон | `concrete` | 180 кг | тёмный бетон `#3b3f46`, из него пол полигона |
| Бетон разметки | `concrete_line` | 180 кг | светлая полоса разметки на бетоне |

**Плиты и скосы** — не кубы: у них своя форма меша и коллизии, поэтому
игрок и колёса заезжают по ним плавно.

| Блок | Ключ | Масса | Форма |
|---|---|---|---|
| Стальная плита | `steel_slab` | 100 кг | половина блока; ставится к грани, по которой щёлкнули (на пол — нижняя половина, на потолок — верхняя) |
| Стальной скос 45° | `steel_slope` | 100 кг | клин на весь блок, низкой стороной к игроку |
| Скос 27° — нижний / верхний | `steel_slope_half_low` / `_high` | 50 / 150 кг | два блока подряд дают ровный скос ≈27° (подъём на 1 блок за 2) |
| Скос 14° — 1/4 … 4/4 | `steel_slope_q1` … `q4` | 25 … 175 кг | четыре блока подряд дают ровный скос ≈14° (1 блок за 4) |

### 3.2 Механизмы (категория «Механизмы»)

Механизмы передают **вращение** — у каждого есть скорость в об/мин. Как это
считается, описано в разделе 4.1.

Почти все механизмы ставятся **по грани**: ось механизма смотрит вдоль
нормали той грани, на которую его ставят. Поворачивать уже поставленные
механизмы можно гаечным ключом.

#### Креативный мотор (`creative_motor`, 120 кг)

Источник вращения: работает всегда, топливо и энергия не нужны.

- **Выход**: вал, торчащий с лицевой стороны; вращение уходит только через эту грань.
- **Настройки ключом**:
  - «Скорость» — 0–256 об/мин, шаг 8, по умолчанию 32;
  - «Направление» — по часовой или против часовой, если смотреть на выход.
- Несколько моторов в одной сети работают вместе, только если хотят одну и
  ту же скорость. Иначе — конфликт, и сеть стоит.

#### Вал (`shaft`, 15 кг)

Передаёт вращение вдоль своей оси с обоих концов. Тонкий, коллизия
0,375 блока в сечении. Повёрнутый поперёк вал разрывает линию.

#### Шестерня (`cogwheel`, 20 кг)

- Вдоль оси работает как вал.
- Боком зацепляется с соседними шестернями той же оси.
- Две малые шестерни рядом: обороты те же, направление обратное.

#### Большая шестерня (`large_cogwheel`, 40 кг)

| С чем зацепляется | Где стоит | Передача |
|---|---|---|
| Малая шестерня | по диагонали | малая → большая: скорость ×½; большая → малая: ×2 |
| Другая большая шестерня | через клетку | скорость та же, направление обратное |

Модель большая и выходит за пределы своей клетки, как в Create.

#### Коробка передач (`gearbox`, 80 кг)

Стальной корпус с четырьмя выходами по кругу вокруг своей оси (кроме двух
торцов вдоль оси).

- **Поворачивает** вращение на 90°.
- Вал, проходящий **насквозь**, получает обратное направление.
- Ключом можно повернуть, чтобы сменить плоскость выходов.
- Стоящий в выходе вал виден по латунной заглушке на корпусе — она
  крутится вместе с ним.

#### Вертикальная коробка передач (`vertical_gearbox`, 80 кг)

Как коробка передач, но ставится «лицом» к игроку: выходы — вверх, вниз,
влево и вправо, ось — от игрока. Удобна, чтобы поднять вращение на этаж
выше без лишних шестерён.

#### Муфта (`clutch`, 60 кг)

Вал в корпусе с красной полосой. Пока на неё приходит сигнал (+ или −),
она **размыкается** и дальше вращение не идёт. Без сигнала работает как
обычный вал.

#### Реверс (`gearshift`, 60 кг)

Вал в латунном корпусе. Пока приходит сигнал, вращение на выходной
стороне становится **обратным**.

#### Регулятор скорости (`speed_controller`, 70 кг)

Вход сзади, выход спереди. На выход отдаёт **свою** скорость, но только
пока на вход что-то крутится. Если вход стоит, выход тоже стоит.

Настройки ключом:
- «Скорость» — −256…256, по умолчанию 32: скорость без сигнала;
- «Скорость по сигналу» — −256…256, по умолчанию 128.

Как работает сигнал:
- сигнал «+» плавно ведёт выход к «скорости по сигналу»;
- сигнал «−» — к той же скорости, но в обратную сторону.

**Педаль газа**: поставьте «Скорость» = 0. Тогда без кнопки машина стоит,
«+» — вперёд, «−» — назад.

#### Подвеска (`suspension`, 60 кг)

Кронштейн с пружиной. Ставится на кузов так, чтобы её ось смотрела наружу,
к колесу; колесо ставится на её внешнюю грань.

- Передаёт вращение к колесу вдоль своей оси.
- По сигналу **поворачивает** колесо.
- Настройки ключом:
  - «Поворот» — 0–45°, шаг 5, по умолчанию 30: угол поворота колеса при сигнале;
  - «Жёсткость» — 1–10, по умолчанию 5: жёсткость пружины в физическом режиме.

#### Спидометр (`speedometer`, 20 кг)

Корпус с крыльчаткой. Измеряет скорость физической конструкции, на которой
стоит (км/ч = м/с × 3,6). В сетке мира показывает 0. Сам ничего не
выводит — его читает датчик телеметрии (см. 3.3).

#### Колесо (`wheel`, 30 кг)

Резиновая шина из 16 сегментов с протектором, латунный обод, стальной
диск, ступица с болтами; радиус 0,6 блока.

- Крутится от кинетической сети, как вал.
- Своей коллизии не имеет: в физическом режиме касается земли через
  пружину подвески (см. 4.5).
- Колесо без привода катится свободно и крутится по скорости машины.

#### Механический подшипник (`mechanical_bearing`, 60 кг)

Корпус с поворотной деревянной платформой на лицевой грани. Вход вращения —
вал сзади. Всё, что приклеено к блоку на его лицевой грани (через сам
подшипник клей не проходит), становится отдельным телом на шарнире и
поворачивается со скоростью вала. Сигнал (пульт, рычаг, провод) поворачивает
платформу к «Углу фиксации» (0–345°, шаг 15°) и держит её там. Работает и в
мире (поворотный стол, ворота, ветряк), и на физической машине (кран).
Подробно — 4.13.

#### Механический поршень (`mechanical_piston`, 80 кг)

Корпус с выдвижной головкой. Вход вращения — вал сзади. Выдвигает
приклеенную перед ним группу: **один блок за полный оборот вала**, до «Хода»
(1–16 блоков); вращение в другую сторону втягивает её. Остановившись на целом
блоке, группа снова становится обычными блоками, а за ней — шток.

#### Цистерна (`fluid_tank`, 100 кг)

Стальной каркас, стеклянные стенки, внутри виден уровень. **16 000 mB** на
блок. Цистерны рядом объединяются в одну, если образуют линию 1×N или колонну
1×1, 2×2, 3×3 любой высоты; жидкость оседает вниз. Настройка «Режим»:
«Хранение» или «Балласт» (набирает забортную воду через помпу, см. 4.15).
Пустая цистерна держится на воде (подъём 1000 кг).

#### Труба (`fluid_pipe`, 10 кг) и труба в кожухе (`cased_pipe`)

Медная труба соединяется со всеми соседними жидкостными блоками и рисует к
ним патрубки. ПКМ медным или стальным корпусом по трубе — надеть кожух
(`cased_pipe`), по валу — `cased_shaft`; Shift + ПКМ ключом — снять кожух.

#### Вал в кожухе (`cased_shaft`, 40 кг)

Вал в стальном корпусе: работает как вал.

#### Механическая помпа (`mechanical_pump`, 70 кг)

Медный корпус-труба с латунной шестернёй. Крутится как шестерня (от
соседней шестерни сбоку или вала вдоль оси) и перекачивает жидкость из сети
за собой в сеть перед собой: **|об/мин| × 8 mB/с**. «Направление»: «Вперёд» /
«Назад».

#### Дизельный двигатель (`diesel_engine`, 250 кг)

Тёмный блок с тремя цилиндрами, медными трубками, выхлопной трубой сверху и
маховиком спереди. Выход — вал спереди; топливо — трубой с любой другой
стороны. Сжигает **10 mB/с** дизеля, пока работает; нужен воздух: над
двигателем нет блока, и выхлоп не под водой. Настройки — скорость (0–256
об/мин) и направление, как у мотора. Дымит и гудит.

#### Маховик (`flywheel`, 150 кг)

Тяжёлый латунный диск на валу: копит энергию и покрывает до 1000 SU
перегрузки на 2 секунды (4.12a).

#### Цепь (`chain`, инструмент)

ЛКМ по шестерне, затем по другой шестерне с той же осью в той же плоскости
(до 16 блоков, под любым углом) — между ними натягивается цепь; ЛКМ по
третьей продолжает цепь от второй, и так далее. **Где щёлкнуть шестерню**
(с какой стороны от линии цепи) — так цепь её и обойдёт: сверху или снизу.
Шестерни по одну сторону цепи крутятся в одну сторону, по разные — в
противоположные; малая → большая вдвое медленнее. ПКМ по шестерне снимает
её цепи, ПКМ в воздух — отмена. Цепи переезжают вместе с конструкцией.

#### Механическая лента (`mechanical_belt`, инструмент)

ЛКМ по валу, затем по другому валу с той же осью на одной линии поперёк
оси: **прямо, вертикально или под 45°**, 2–20 блоков, между ними пусто.
Валы становятся шкивами, промежуток — лентой; оба шкива крутятся одинаково.
Ровная и наклонная лента **везёт** стоящего на ней игрока и физические тела
(скорость = об/мин × 2π × 0,5 м / 60). Сломать шкив или кусок ленты —
лента исчезнет, шкивы снова станут валами.

#### Гусеницы: звёздочка (`track_sprocket`, 60 кг) и каток (`track_roller`, 40 кг)

Ставятся на грань, как колесо (наружу). Ведущая звёздочка крутится от вала
сзади; катки рядом в ряд с той же осью крутятся вместе с ней — гусеничная
лента обтягивает ряд сама. Каждый блок ряда опирается о землю своей
пружиной (подвеска не нужна), бокового сцепления больше, чем у колёс;
поворачивают разной скоростью левой и правой гусениц.

### 3.3 Управление (категория «Управление»)

#### Сиденье (`seat`, 30 кг)

Ставится стоя, лицом к игроку.

- ПКМ — сесть: игрок садится на подушку и едет вместе с сиденьем, в том
  числе на движущейся машине.
- Shift — встать: игрок окажется сверху на сиденье.
- Сидящий игрок управляет всеми пультами рядом.

#### Пульт управления (`control_panel`, 40 кг)

Стальной корпус с наклонной латунной панелью, лампочками и рычагами.

- Ставится лицом к игроку.
- Работает, когда игрок сидит на сиденье той же постройки, не дальше
  3,5 блока от пульта.
- Тогда пульт читает клавиатуру и передаёт её всем связанным датчикам.

#### Датчик (`sensor`, 5 кг)

Пластина с антенной и зелёной лампой. Принимает сигнал пульта и передаёт
его блоку, на котором стоит.

- Ставится **на блок, которым управляет**: смотрит в него. Подходящие
  блоки — подвеска, муфта, реверс, регулятор скорости.
- Коллизии нет.
- Связь с пультом делается гаечным ключом: ЛКМ по пульту, затем ЛКМ по
  датчику. Сразу откроется окно настроек датчика.
- Настройки:
  - «Клавиша (+)» — по умолчанию W;
  - «Клавиша (−)» — по умолчанию не назначена.
- Можно выбрать: W, S, A, D, Пробел, Q, R, F, Z, X, C, стрелки. Shift и E
  назначить нельзя: Shift — встать с сиденья, E — инвентарь.
- Сигнал: зажата «+» → +1, зажата «−» → −1, обе или ни одной → 0.

#### Датчик телеметрии (`telemetry_sensor`, 5 кг)

Ставится на блок-источник данных (смотрит в него, как обычный датчик),
коллизии нет. Что читает:

| На чём стоит | Значение | Диапазон |
|---|---|---|
| Спидометр | скорость, км/ч | 0–200 |
| Подвеска | угол поворота колеса, ° | 0–45 |
| Любой вращающийся блок (мотор, вал, шестерня, колесо…) | обороты по модулю | 0–256 |

Связь с экраном — гаечным ключом: ЛКМ по датчику телеметрии, затем ЛКМ по
экрану. Связь переезжает вместе с конструкцией и копируется чертежом.

#### Механический экран (`mechanical_display`, 50 кг)

Стальной корпус с лицевой панелью. Показывает значение связанных датчиков
(если их несколько — наибольшее). 2D-интерфейса нет — всё на самом блоке.

- **Питание вращением.** Экран работает, только пока его крутит шестерня
  или вал **сбоку** (слева или справа от лицевой панели). Без вращения
  панель гаснет, стрелка падает на ноль, зелёная лампа питания не горит.
- **Настройки ключом:**
  - «Вид» — «Цифры» (три светящихся 7-сегментных разряда и янтарная полоса
    из 10 ячеек) или «Стрелка» (циферблат с 9 делениями, два последних
    красные; стрелка движется плавно);
  - «Максимум шкалы» — 32–256 (шаг 32, по умолчанию 128): значение, при
    котором стрелка и полоса доходят до конца.

#### Фара (`headlight`, 15 кг)

Ставится на грань и светит вдоль неё: стеклянная линза и тёплый луч
(прожектор дальностью 45 м). Управляется сигналом: свяжите пульт с
датчиком, поставленным на фару, — **каждое нажатие** клавиши включает или
выключает её (удерживать не нужно).

#### Бесконечный бак (`creative_tank`, «Механизмы», 100 кг)

Источник для своей трубной сети: никогда не пустеет. Ключом — жидкость
(вода или дизель). Для стендов и испытаний.

#### Заливной порт (`fluid_port`, 30 кг)

Корпус с воронкой и люком. ПКМ **ведром дизеля** — +1000 mB; порт сразу
сливает топливо в цистерны своей трубной сети (или отдаёт его двигателю).

#### Переключатель физики (`physics_toggle`, 80 кг)

Стальной корпус с латунным крестом и светящимся янтарным ядром.

- ПКМ по нему делает **физическим телом** его самого и всё, что приклеено к
  нему клеем.
- Если ничего не приклеено, физическим становится только он.
- ПКМ ещё раз — тело встаёт обратно в сетку блоков (подробно в 4.4).

#### Раздвижная дверь (`sliding_door`, «Строительные»)

Две клетки в высоту (верх ставится сам). ПКМ — открыть / закрыть; сигнал
логики (рычаг, провод, кнопка рядом) открывает, пока держится, и закрывает,
когда пропадает. Створка уезжает вбок, открытая дверь пропускает.

#### Формы блоков

Любой строительный блок (камень, доски, сталь, бетон, стекло, корпуса…)
ставится в шести формах: **куб, плита, ступенька, скос 45°, внешний угол,
внутренний угол**. Форма выбирается **Shift + колесо** с блоком в руке
(видна в названии предмета), СКМ по фигурному блоку берёт его материал и
форму. Скосы и ступеньки ставятся низкой стороной к игроку.

### 3.4 Логика (категория «Логика»)

Сигнал — только «есть / нет», без затухания. Как он идёт — 4.16.

| Блок | Ключ | Что делает |
|---|---|---|
| Провод | `wire` | лежит на грани блока; одинаковые цвета в соседних клетках соединяются (и через ребро блока); 8 цветов: Shift + колесо с проводом в руке — цвет новых, ЛКМ ключом — перекрасить проложенный |
| Кнопка | `button` | ПКМ — импульс 0,8 с |
| Рычаг | `lever` | ПКМ — вкл/выкл (ручка показывает положение) |
| Таймер | `timer_block` | импульс 0,3 с каждые «Интервал» секунд (0,5–60); стрелка на циферблате |
| Генератор импульсов | `pulse_generator` | из включения сигнала делает короткий импульс вперёд |
| Логический элемент | `logic_gate` | «Режим»: И, ИЛИ, НЕ, RS-триггер; входы слева, справа и сзади, выход спереди (по стрелке) |
| Мигалка | `flasher_light` | лампа под стеклянным куполом; вспыхивает на импульс, мигает, пока сигнал держится |
| Лампа | `lamp` | ровный тёплый свет (настоящий источник света), пока есть сигнал |
| Пороговый датчик | `threshold_sensor` | крепится на блок и читает его, как датчик телеметрии (скорость, обороты, угол, заполнение бака, загрузка двигателя); даёт сигнал, пока значение не меньше (или не больше) «Порога». Пример: «бак полон → выключить помпу» |
| Радиопередатчик | `radio_transmitter` | пока на него приходит сигнал (логика или пульт), включён его канал 1–16 — для всех приёмников этого канала |
| Радиоприёмник | `radio_receiver` | даёт сигнал соседям, пока включён его канал: ворота с пульта машины, свет на другом конце полигона без проводов |

### 3.5 Инструменты (категория «Инструменты»)

#### Гаечный ключ (`wrench`)

| Кнопка | Действие |
|---|---|
| ПКМ по блоку | повернуть его на 90° вокруг оси той грани, по которой щёлкнули (как в Create). Сиденье и пульт крутятся только вокруг вертикали. Настройки сохраняются |
| ЛКМ по блоку с настройками | окно настроек: строка на каждый параметр с кнопками ‹ › и текущими оборотами. Если скорости в сети спорят, в окне видно «конфликт скоростей». Esc — закрыть |
| ЛКМ по пульту, затем по датчику | связать их |
| ЛКМ по датчику телеметрии, затем по экрану | связать их |

#### Клей (`glue`)

| Кнопка | Действие |
|---|---|
| ЛКМ по блоку | первый угол объёма |
| ЛКМ по второму блоку | второй угол: всё внутри этого прямоугольного объёма склеено |
| ПКМ по блоку | снять клей с объёма, в который он входит |

Склеенные объёмы видны зелёными рамками, пока клей в руке. Будущий объём
подсвечивается жёлтым.

#### Гравитационная пушка (`gravity_gun`) — как в Half-Life 2

| Кнопка | Действие |
|---|---|
| ПКМ по физическому телу (до 14 м) | притянуть и держать в 2,5 м перед собой |
| ПКМ ещё раз | отпустить |
| ЛКМ | толкнуть удерживаемое тело или то, на которое смотришь (до 8,4 м) |

- Толчок одинаковый для всех: лёгкое улетает быстрее, скорость не больше 30 м/с.
- Тела тяжелее 1,5 т поднять нельзя, только толкать.
- Янтарный луч показывает захват.

#### Физическая пушка (`physgun`) — как в Garry's Mod

| Кнопка | Действие |
|---|---|
| Зажать ЛКМ на теле (до 60 м) | схватить за точку, куда попал луч; тело следует за прицелом |
| Колесо мыши | ближе / дальше (1,5–60 м) |
| E + мышь | вращать тело (взгляд в это время не двигается) |
| ПКМ, удерживая | **заморозить** в воздухе |
| ЛКМ по замороженному | схватить снова (размораживается) |
| R, глядя на замороженное | разморозить: оно падает |

Голубой луч показывает захват.

#### Ведро воды (`bucket_water`)

ПКМ по заливному порту — +1000 mB воды. Не кончается.

#### Ведро дизеля (`bucket_diesel`)

ПКМ по заливному порту — +1000 mB дизеля. В творческом режиме не кончается.

#### Инженерные очки (`engineer_goggles`)

Надеваются в слот **«Голова»** (инвентарь, слева от сетки; Shift + щелчок
надевает и снимает). Пока надеты, рядом с прицелом панель с данными блока:
обороты, нагрузка / мощность сети и перегрузка, жидкость, состояние
двигателя, заряд маховика, сигнал и логика. Видны и на модели игрока.

В инвентаре 4 слота экипировки: голова, тело, ноги, обувь (пока для очков).

#### Чертёж (`blueprint`)

Копирует постройку и ставит копию в другом месте.

| Кнопка | Действие |
|---|---|
| ЛКМ по блоку | скопировать его склеенную группу (всё, что приклеено к нему; если ничего — только блок) или всю физическую конструкцию |
| Чертёж в руке | синяя голограмма показывает, куда встанет копия; красная — место занято |
| R | повернуть копию на 90° |
| ПКМ | поставить копию обычными блоками |

- Копируются настройки блоков, связи пультов и датчиков (только внутри
  копии) и клей.
- Последняя копия пишется в `schematics/saved_contraption.ron`.
- Консоль: `save <имя>` — сохранить текущую копию как именованный чертёж
  (`schematics/<имя>.ron`), `load <имя>` — взять его в чертёж,
  `blueprints` — список сохранённых.

## 4. Механики

### 4.1 Кинетическая сеть (вращение)

Вращение не считается физикой, как и в Create:
- соседние механизмы соединяются по правилам;
- скорость передаётся по связям с постоянными передаточными числами;
- сеть пересчитывается каждый кадр, отдельно для мира и для каждого
  физического тела.

Поэтому механизмы работают **одинаково в блоках и в физическом теле**.

**Правила связи:**

| Связь | Условие | Передача |
|---|---|---|
| По оси | два механизма смотрят друг на друга своими выходами: концы вала, выход мотора, стороны коробки | скорость та же |
| Малая шестерня — малая | рядом, одна ось | ×−1 |
| Малая — большая | по диагонали, одна ось | ×−½ или ×−2 |
| Большая — большая | через клетку, одна ось | ×−1 |
| Коробка передач | вход и выход под углом 90° | направление зависит от сторон; насквозь — обратное |

**Ограничения:**
- Если в одной сети источники хотят разную скорость — **конфликт**, вся сеть стоит.
- Самая быстрая деталь сети не крутится быстрее **256 об/мин**: при
  необходимости вся сеть пропорционально замедляется.
- Креативные моторы бесконечно мощные: нагрузки и поломок пока нет.

Регулятор скорости считается в два прохода: сначала проверяется, крутится
ли его вход, потом его выход становится источником.

### 4.2 Сигналы

Цепочка: **игрок на сиденье → пульт рядом → связанные датчики → блоки**.

Сигнал −1…1 обновляется каждый кадр и сразу пропадает, если клавишу
отпустить. Что делает каждый блок:

| Блок | Сигнал ≠ 0 |
|---|---|
| Муфта | разомкнута |
| Реверс | выход обратный |
| Регулятор скорости | выход ведётся к ±«скорости по сигналу» |
| Подвеска | колесо поворачивается на −сигнал × «Поворот»° (плавно, около 140°/с) |
| Фара | каждое нажатие (сигнал из 0 в ≠ 0) включает или выключает |
| Подшипник | поворачивает платформу к «Углу фиксации» и держит |

Тот же сигнал эти блоки получают от логики: рычага, кнопки, таймера,
провода или логического элемента рядом (4.16).

На одну подвеску могут работать два датчика, например A и D. Их сигналы
складываются (не больше ±1).

### 4.3 Клей

Клей — это список прямоугольных объёмов клеток. Два соседних по грани блока
**сцеплены**, если оба лежат внутри одного объёма. Всё, до чего можно дойти
от переключателя по сцепленным соседям, становится одним телом.

### 4.4 Физический режим (конструкции)

**Включение** (ПКМ по переключателю физики):
1. Собирается группа: переключатель и всё приклеенное к нему.
2. Блоки уходят из сетки мира в новую сетку — одно твёрдое тело.
   Механизмы, их настройки, связи датчиков и клей переезжают вместе с ними.
3. Форма тела — коробки коллизий его блоков. Масса — сумма масс блоков
   (поле `mass`), центр масс считается по ним же.

**Выключение** (ПКМ по переключателю ещё раз):
1. Тело поворачивается к ближайшему положению, совпадающему с сеткой.
2. Каждый блок ставится в ближайшую клетку мира.
3. Если хотя бы одна клетка занята, игра пишет «Нет места…» и тело
   остаётся физическим.

### 4.5 Колёса и езда

Используется «лучевая» подвеска. Для каждого колеса на подвеске:

- **Пружина.** Из центра колеса вниз (по «верху» машины) опускается
  небольшой шар-проба (радиус 0,25) — не тонкий луч: он плавно перекатывается
  через края блоков, ступеньки и стыки скосов. Пружина и демпфер толкают
  корпус вверх в точке контакта.
  - Жёсткость подобрана так, что в покое кузов стоит на 0,25 блока выше,
    чем построен (просвет), — блоки на уровне оси не задевают кочки.
  - Колесо видно опускается за землёй на ходу подвески.
  - Настройка «Жёсткость» подвески её усиливает или ослабляет.
  - Ход подвески — 0,35 блока.
- **Тяга.** Скорость колеса из кинетической сети задаёт нужную скорость
  машины по земле: скорость = обороты × 2π × 0,6 м / 60. Сила тяги
  ограничена сцеплением колеса.
- **Боковое сцепление** гасит скольжение вбок, поэтому машина едет по курсу.
- **Руление.** Направления тяги и сцепления поворачиваются на угол поворота
  подвески.
- **Тормоз.** Колёса, связанные с источником вращения (мотором), держатся
  трансмиссией: при 0 об/мин машина стоит и на склоне.
- **Свободное колесо** (сеть без источника) катится и крутится по скорости
  машины.
- Подвеска проверена на полигоне: гладкие эстакады 15° и 30°, скосы из
  блоков 27° и 14°, «гребёнка» (см. 4.11).

Колёса — не отдельные тела на шарнирах. Такие колёса в Avian дрожат на
тяжёлых машинах и дороже для FPS; лучевая подвеска устойчива и дешёвая.

**Пример машины** (так она собрана в автотесте):
- рама из стальных блоков;
- по углам — подвески наружу, на них колёса;
- задние колёса через шестерни крутит регулятор скорости (скорость 0,
  «скорость по сигналу» 96, датчик с W/S), а его — мотор;
- на передних подвесках датчики с A/D;
- наверху сиденье, пульт и переключатель физики;
- всё склеено одним объёмом.

ПКМ по переключателю → сесть → W едет, A/D рулят.

### 4.6 Физические инструменты

Захваченное пушкой тело ведётся на **каждом шаге физики**: скорость тела
направляется к нужной точке. Поэтому удержание устойчиво при любом FPS.

**Заморозка** физпушкой делает тело статичным: оно висит в воздухе и
служит опорой. Разморозка возвращает ему физику.

### 4.7 Игрок

- Игрок — физическое тело-капсула 0,6 × 1,8 м, в приседе 1,5 м.
- Вращаться капсула не может. Тяжесть ×2,6, чтобы прыжок ощущался как в
  Minecraft.
- Каждый шаг физики скорость плавно ведётся к желаемой, поэтому толчки и
  столкновения остаются физичными.
- **Защита от падения при приседании.** Перед шагом проверяется, будет ли
  под ногами опора — по каждой оси и по диагонали. Если нет — движение
  отменяется; если игрок всё же съехал (толчок, лента), его возвращает на
  последнюю надёжную точку.
- Встать из приседа нельзя, если над головой нет места.

### 4.8 Время

- Часы идут от 0 до 24; по умолчанию сутки длятся 20 реальных минут.
- Солнце движется по небу, ночью слабый лунный свет.
- Цвет неба, горизонта и окружающего света следует за временем; утром и
  вечером свет тёплый.

**Меню F3:**
- FPS, координаты, время и его скорость;
- кнопки: стоп/пуск времени, −1 ч / +1 ч, Утро / День / Вечер / Ночь,
  скорость ×1 / ×10 / ×60, полёт.

**Консоль (T или /).** Ввод, Enter — выполнить:

| Команда | Что делает |
|---|---|
| `help` | список команд |
| `time set <часы>` | установить время, например `time set 7.5`; можно `morning`, `day`, `evening`, `night` (и по-русски: `утро`, `день`, `вечер`, `ночь`) |
| `time stop` / `time start` | остановить / запустить время |
| `time speed <×>` | скорость времени относительно обычной |
| `tp x y z` | телепорт (y — уровень ног) |
| `fly` | полёт вкл/выкл |
| `give <ключ> [n]` | выдать предмет по ключу, например `give creative_motor` |
| `clear` | очистить инвентарь |
| `save <имя>` | сохранить копию из чертежа как `schematics/<имя>.ron` |
| `load <имя>` | загрузить именованный чертёж в инструмент «Чертёж» |
| `blueprints` | список сохранённых чертежей |

### 4.9 Инвентарь и каталог

- **Хотбар** — 9 ячеек внизу экрана.
- **Инвентарь** (E) — 6 строк по 9 ячеек, хотбар ниже.

**Щелчки в инвентаре** (как в Minecraft):

| Щелчок | Действие |
|---|---|
| ЛКМ | взять стопку / положить / поменять / соединить одинаковые |
| ПКМ | взять половину / положить по одному |
| Shift + ЛКМ | перекинуть стопку между хотбаром и инвентарём |

**Каталог** (кнопка «Все предметы»):
- слева категории: Все, Строительные, Механизмы, Управление, Инструменты;
- в центре сетка предметов с прокруткой колесом;
- внизу поле поиска: щёлкнуть и печатать, ищет по названию и ключу;
- ЛКМ по предмету — взять полную стопку на курсор;
- Shift + ЛКМ — сразу в хотбар;
- щелчок по каталогу со стопкой на курсоре — выбросить её.

Название предмета под курсором показывается в заголовке окна.

### 4.10 Телеметрия

Цепочка: **источник → датчик телеметрии → механический экран**.

- Пример на машине: спидометр, на нём датчик телеметрии, рядом экран, сбоку
  от экрана шестерня от мотора. Ключом: ЛКМ по датчику, ЛКМ по экрану. На
  ходу экран показывает км/ч; ключом «Вид» — цифры или стрелка.
- Экран без вращения не работает, даже если связан: так он остаётся
  частью механики, а не «бесплатным» HUD.
- Значение обновляется каждый кадр; стрелка догоняет его плавно.

### 4.11 Инженерный полигон

Испытательная зона на западном краю платформы (x от −63 до −29), подальше от
центра, где идёт стройка. Пять дорожек шириной 6 блоков с шагом 7 ведут в
сторону −Z на плато высотой 3 блока (8 блоков ровно) и обратно вниз:

| № | Дорожка | Из чего |
|---|---|---|
| 1 | гладкая эстакада 15° | цельное статичное тело из бетона |
| 2 | гладкая эстакада 30° | то же |
| 3 | скос ≈27° | половинные скосы на бетонных блоках |
| 4 | скос ≈14° | четвертные скосы на бетонных блоках |
| 5 | «гребёнка» | стальные плиты через клетку, 48 м |

Гладкие эстакады — образец будущего рельефа; скосы из блоков — то, что
строит игрок. Автотест проезжает машиной все пять дорожек.

### 4.12 Звуки

Звуки свободные (CC0), список источников — `assets/sounds/CREDITS.md`:
Kenney (Sci-Fi и Interface Sounds), artisticdude (RPG Sound Pack), BMacZero
(Mechanical Sounds), Spring Spring (Steamboat Engine Sound — гул дизеля),
GGBotNet (Car Sound Effects Pack — дизель глохнет).

- Пространственные: ломать и ставить блоки (металл, дерево), поворот
  ключом, клей, связь ключом, фара, сиденье, включение и выключение
  физики, гравипушка и физпушка (захват, отпускание, толчок, заморозка).
- Интерфейс: открыть/закрыть окно, щелчок в настройках.
- Работающие моторы гудят, дизель стучит: до 4 ближайших в радиусе 18 м,
  высота тона зависит от оборотов.

### 4.12a Мощность, нагрузка и перегрузка (SU)

Как в Create: у вращения есть **мощность** источников и **нагрузка**
потребителей в единицах нагрузки (SU, stress units).

- **Источники.** Креативный мотор — настройка «Мощность» (по умолчанию
  16 384 SU). Дизельный двигатель — 2048 SU, пока есть топливо и воздух.
- **Потребители**: каждый блок берёт `база × |об/мин| / 32` SU.

| Блок | База, SU |
|---|---|
| Вал, вал в кожухе, подвеска, колесо, муфта, реверс | 0,5 |
| Шестерня, механический экран, регулятор скорости, маховик | 1 |
| Большая шестерня, коробка передач, подшипник, поршень | 2 |
| Помпа | 12 |

- **Колёса под нагрузкой** (физический режим, ведущее колесо на земле)
  добавляют на 32 об/мин: качение `масса / 4 × 0,08` и подъём
  `масса × sin θ` — только когда колесо тянет вверх по склону (на спуске
  торможение двигателем мотор не перегружает).
- Сети, связанные через регулятор скорости, делят мощность и нагрузку.
- **Перегрузка**: если нагрузка больше мощности, вся сеть замедляется в
  `мощность / нагрузка` раз. Меньше 0,2 — сеть стоит. Дизель при этом
  **глохнет**: клуб чёрного дыма и кашель. Заведётся сам, когда сеть
  смогла бы работать хотя бы на половине скорости: отпустите газ или
  включите пониженную передачу.
- **Зачем передачи.** Нагрузка пропорциональна оборотам: малая шестерня →
  большая вдвое снижает обороты колёс и вдвое — нагрузку. Тяжёлая машина на
  дизеле глохнет на эстакаде 30° на прямой передаче и заезжает с редуктором.
  Пониженная передача из регулятора скорости работает так же.
- **Маховик** (`flywheel`, 150 кг) копит энергию из запаса мощности и при
  перегрузке отдаёт до 1000 SU на 2 секунды: старт с места, «гребёнка».
- **Видно**: окно ключа пишет «Нагрузка: N / M SU» и перегрузку; датчик
  телеметрии на двигателе или моторе показывает загрузку сети в процентах —
  на стрелке 100 % — начало красной зоны, цифры при перегрузке красные.

### 4.13 Подшипник и поршень

- Подвижная часть — отдельное физическое тело на шарнире Avian
  (`RevoluteJoint` у подшипника, `PrismaticJoint` у поршня), соединённое с
  сеткой, где стоит подшипник: миром или физической машиной. Шарнир ведёт
  мотор шарнира к нужному углу / выдвижению, поэтому часть несёт груз и
  упирается в препятствия.
- Через сам подшипник или поршень клей не проходит: на платформу попадает
  только то, что приклеено к блоку перед ним.
- Остановившись на кратном 90° угле (подшипник) или на целом блоке (поршень),
  часть снова становится блоками сетки.
- Если выключить физику машины с краном, сначала кран встаёт в ближайшее
  положение и возвращается в машину, потом вся машина — в мир.

### 4.14 Жидкости

- Единица — милливедро (mB): ведро 1000 mB, блок цистерны 16 000 mB.
  Жидкости: вода и дизель (в одной цистерне — одна жидкость).
- **Трубная сеть** — соединённые гранями трубы, трубы в кожухе, цистерны,
  порты и двигатели (у двигателя — все грани, кроме выхода). Внутри сети
  порт сам сливает в цистерны (до 2000 mB/с), двигатель сам берёт топливо
  (до 250 mB/с в свой бак на 1000 mB).
- **Помпа** — граница двух сетей: переносит жидкость из сети сзади в сеть
  спереди (|об/мин| × 8 mB/с, «Назад» — наоборот).
- Всё считается для каждой сетки отдельно, поэтому топливный бак на машине и
  балласт подлодки работают и в физическом режиме.
- Датчик телеметрии на цистерне показывает её заполнение в процентах.

### 4.15 Вода и плавучесть

- Вода — объём бассейна, а не блоки. **Плавание:** когда игрок погружён
  больше чем на треть, вода держит его почти как в жизни — медленно
  тонет, вязко тормозит, разгоняется плавно. Пробел — всплыть, Shift —
  нырнуть, WASD — плыть по взгляду (2,6 м/с, с Ctrl в 1,5 раза быстрее).
  У стенки бассейна Пробел вытягивает на берег. Под водой — синий туман.
- Каждый блок физической конструкции под водой выталкивается вверх
  (закон Архимеда): «плавучесть» блока в `blocks.ron` — подъём в кг при
  полном погружении; по умолчанию 40 % массы, поэтому механизмы и сталь
  тонут, а доски, стекло, рамы и пустые цистерны держатся на воде.
- Жидкость в цистернах весит (полный блок воды — 1000 кг, как вода, которую он
  вытесняет). Поэтому балласт работает: помпа, у которой один конец открыт
  в воду снаружи, набирает воду в цистерны в режиме «Балласт» — подлодка
  тяжелеет и погружается; помпа в другую сторону откачивает воду — всплывает.
- Вода тормозит движение (вертикально сильнее).

### 4.16 Логика

- **Соседство, как редстоун.** Работающий источник (рычаг, нажатая кнопка,
  импульс таймера) питает блоки со всех шести сторон; логический элемент и
  генератор импульсов — только блок перед собой.
- **Провода** ставятся на любую грань блока, несколько проводов на один блок —
  на разные грани. Провода одного цвета в соседних клетках — одна линия, в
  том числе через ребро блока (сверху и сбоку). Разные цвета не соединяются.
  Линия включена, если любой её провод касается работающего источника, и
  тогда питает все блоки, которых касаются её провода. Включённый провод
  светится.
- Питаемый блок, который принимает сигнал (муфта, реверс, регулятор, подвеска,
  фара, подшипник, мигалка, элементы), получает сигнал 1.
- **Логический элемент** читает левый, правый и задний входы и выдаёт
  результат спереди с задержкой в один кадр (поэтому петли не зависают):
  И — левый и правый; ИЛИ — любой; НЕ — ни одного; RS-триггер — левый
  включает и запоминает, правый сбрасывает.

### 4.17 Главное меню, пауза и настройки

- **Главное меню** — над медленным облётом полигона: «Играть», «Настройки»,
  «Выход».
- **Пауза** (Esc в игре) останавливает мир: «Продолжить», «Настройки»,
  «В главное меню», «Выход».
- **Настройки** (‹ значение ›), применяются сразу и сохраняются в
  `settings.ron` (в собранном приложении — в
  `~/Library/Application Support/Sandbox`):

| Вкладка | Что есть |
|---|---|
| Графика | окно / полный экран, разрешение, **масштаб рендера 50–100 %**, вертикальная синхронизация, ограничение FPS (нет, 30, 60, 120, 144), тени, контактные тени (SSAO, по умолчанию выкл.), свечение (bloom), дальность прорисовки |
| Звук | общая громкость, эффекты, моторы и двигатели, интерфейс |
| Управление | чувствительность мыши, инверсия по Y, поле зрения (55–110°), клавиши: вперёд, назад, влево, вправо, прыжок, присесть, бег, инвентарь, вид камеры (щёлкнуть и нажать новую; Esc — отмена) |

## 5. Визуальный стиль

Ориентиры — присланные референсы:
- общий вид — Hytale и Minecraft;
- механизмы — Create;
- инструменты — клёпаная сталь, латунь, светящиеся ядра.

Ничего не скопировано: все текстуры сгенерированы своим скриптом, модели
собраны в коде.

- **Пиксели.** Текстуры 32 × 32 на блок, без размытия. Палитры по 4–6
  ступеней, свет сверху слева, тёмная обводка снизу справа.
- **Фаска.** У каждой текстуры внутренняя фаска 2 пикселя: верх и левый
  край на 15 % светлее, низ и правый на 15 % темнее, плюс мягкий градиент.
  Детали моделей получают то же затенение вершинным цветом (верх светлее,
  низ темнее), поэтому бруски выглядят объёмными.
- **Материалы:**

| Материал | Цвета | Где используется |
|---|---|---|
| Белый | `#c9ccd1 → #f6f7f8` | белый блок |
| Тёмный бетон | `#3b3f46`, разметка светлее | пол полигона |
| Тёмная сталь | `#2b2e35 → #767d89` | клёпаные плиты, рамы, корпуса |
| Латунь | `#6b4816 → #f2d58c` | шестерни, болты, обода |
| Медь | `#6e3018 → #f0a066` | катушки мотора, пружины |
| Тёмное дерево | `#3b2414 → #94673c` | доски, вставки корпусов, сиденье |
| Резина | — | шины |
| Андезит | — | валы |
| Красная рукоять | — | ключ, рычаги, полоса муфты |
| Кожа | — | — |

- **Одна плотность пикселей.** Модели механизмов и инструментов собраны
  из «пиксельных брусков»: на брусок ложится текстура с той же плотностью
  32 точки на метр, что и у блоков. Поэтому маленькие детали выглядят
  как кусочек того же пиксель-арта, а не сжатая картинка.
- **Анимация.**
  - Все вращающиеся части крутятся со скоростью своей сети.
  - Соседние шестерни сдвинуты на полузуба, чтобы зубья входили друг в друга.
  - Колёса поворачиваются при рулении, игрок анимирован.
- **Свет — как в Minecraft / Hytale.**
  - Грани блоков затенены по направлению, как в Minecraft: верх 100 %,
    стороны север/юг 82 %, запад/восток 68 %, низ 55 %. Мягкие углы (AO)
    в 4 ступени. Поэтому форма читается даже в тени и без SSAO.
  - Яркий рассеянный свет днём и мягкое солнце; тени — 2 каскада, карта
    1536 (раньше 4 каскада 4096) — заметно легче для видеокарты.
  - Небо: голубой градиент к белёсому горизонту, квадратные солнце и луна,
    блочные облака на высоте 110, которые медленно плывут. Дымка у
    горизонта цвета неба (под водой — синяя), дальние блоки растворяются в ней.
  - HDR и мягкое свечение (bloom); светятся только индикаторы и ядра:
    янтарь, бирюза, зелёный, красный; лампа — настоящий источник света.
- **Игрок** — фигура Minecraft без скина, однотонная светло-серая. Свою
  модель и текстуры можно сделать самому — `docs/MODDING.md`.
- **Иконки** снимаются с тех же 3D-моделей изометрической камерой, поэтому
  всегда совпадают с игрой.
- **Интерфейс** максимально простой:
  - тёмные полупрозрачные панели, серые ячейки;
  - рамки окон `#3a3e47` с латунными заклёпками `#d4a84f` по углам;
  - сообщения (тосты) — на такой же плашке;
  - латунный акцент (выбранный слот, заголовки);
  - шрифт JetBrains Mono с кириллицей.

## 6. Как игра устроена под капотом (простыми словами)

**Всё — плагины.** Игра собрана из независимых частей: мир, игрок,
механизмы, интерфейс и т. д. Каждая часть сама добавляет свои системы
(функции, которые выполняются каждый кадр). Убрать или добавить
возможность — значит подключить или отключить её плагин в `src/main.rs`.

**Блоки — это данные.** Список блоков, инструментов и категорий лежит в
текстовых файлах `assets/content/*.ron`. При запуске игра читает их и
строит реестр. Код обращается к блокам по строковому ключу (`"shaft"`), а не
по номеру, поэтому порядок в файлах можно менять.

**Сетка блоков.** Мир хранится как сетка клеток, разбитая на куски
16 × 16 × 16 (чанки). В каждой клетке — тип блока и его направление
(одна из 6 сторон). Когда клетка меняется, её чанк помечается «грязным».
В конце кадра у грязных чанков заново строятся:
- **меш** — видимые грани кубов (грани, закрытые соседями, пропускаются),
  с затенением углов и координатами в общей текстуре-атласе;
- **коллайдер** — соседние сплошные кубы сливаются в большие коробки
  (пол полигона — это несколько больших коробок, а не тысячи кубиков);
  у механизмов свои коробки по их форме.

**Физические конструкции — та же сетка.** Машина — это ещё одна сетка
блоков, но со своим положением в мире и физическим телом. Всё, что умеет
мир (меш, коллизии, механизмы, прицел), работает и в ней. Поэтому механизмы
внутри машины ничем не отличаются от механизмов на земле.

**Механизмы — блоки-сущности.** Для каждой клетки с механизмом создаётся
отдельная сущность — дочерняя к сетке. У неё есть:
- 3D-модель;
- настройки (`Params`);
- входящий сигнал;
- обороты и угол поворота.

Специальная система следит, чтобы эти сущности всегда соответствовали
клеткам: поставили — появилась, сломали — исчезла, повернули ключом —
повернулась с сохранёнными настройками.

**Вращение — граф.** Каждый кадр механизмы сетки превращаются в узлы графа.
Чистая функция `solve` обходит граф от узла к узлу, умножая скорость на
передаточные числа, и выдаёт обороты каждой клетки. Модели крутятся на
полученный угол. Физика тут не участвует, поэтому это быстро и стабильно.

**Прицел.** Луч из глаз игрока проверяется по каждой сетке: точка
переводится в координаты сетки, и луч шагает по клеткам (алгоритм DDA)
до первого непустого блока. Побеждает ближайшее попадание. Ставить и
ломать можно и в мире, и на машине.

**Физика.** Avian считает тела, столкновения и силы на фиксированном шаге
(64 раза в секунду). Игрок, машины, удерживаемые пушкой объекты управляются
именно на этом шаге — так поведение не зависит от FPS.

**Интерфейс.** Окна — это узлы интерфейса Bevy. Ячейки не хранят предметы,
а каждый кадр показывают данные инвентаря, поэтому интерфейс не может
«разъехаться» с данными. Что сейчас открыто (игра, инвентарь, консоль,
меню, настройки), определяет одно состояние `Ui`. От него зависит, заблокирован
ли курсор и кому достаются клавиши.

**Иконки.** При запуске каждый предмет ставится в невидимую сцену. Отдельная
камера один раз фотографирует их в общую картинку-атлас, и интерфейс
показывает кусочки этой картинки.

## 7. Документация для разработки

### 7.1 Сборка и запуск

```bash
cd Sandbox
cargo run --release                       # играть
cargo test                                # юнит-тесты
cargo run -- --autotest --shots shots     # сценарий-автотест со снимками
AUTOTEST_ONLY=car cargo run -- --autotest --shots shots   # только этапы
python3 tools/texgen/texgen.py --sheet sheet.png          # перегенерировать текстуры
```

- Требуется Rust 1.97.1 (закреплён в `rust-toolchain.toml`).
- Для `texgen` нужны Python 3, numpy и Pillow.
- Без экрана (Linux) автотест запускается через `xvfb-run` с программным
  Vulkan (lavapipe).

### 7.3 Формат данных

**`blocks.ron`** — список блоков:

```ron
(key: "shaft", name: "Вал", category: "mechanisms",
 mech: Some(Shaft),            // поведение (enum Mech), None — простой куб
 textures: Some(("top", "side", "bottom")),   // для кубов
 transparent: false,           // видно насквозь (стекло, рамы)
 placement: Face,              // None | Face | Attach | Horizontal
 shape: Cube,                  // Cube | Slab | Wedge(низ, верх) — высоты клина 0..1
 collision: Box(0.375, 1.0, 0.375),  // Full | None | Box(x, y, z); Y — ось блока
 mass: 15.0,                   // кг в физическом режиме
 params: [                     // настройки для гаечного ключа
    (key: "speed", label: "Скорость",
     kind: Number(min: 0.0, max: 256.0, step: 8.0, unit: "об/мин"), default: 32.0),
    (key: "direction", label: "Направление", kind: Choice(["А", "Б"]), default: 0.0),
    (key: "key_pos", label: "Клавиша", kind: Key, default: 1.0),
 ])
```

**Правила `placement`:**

| Значение | Как ставится |
|---|---|
| `Face` | ось вдоль нормали грани |
| `Attach` | смотрит в блок, по которому щёлкнули |
| `Horizontal` | стоит прямо, лицом к игроку |
| `None` | без направления |

**`tools.ron`**: `(key, name, category, tool: Wrench | Glue | GravityGun | PhysGun | Blueprint)`.

**`categories.ron`**: `(key, name)` в порядке показа.

Для удобства правки файлы читаются с диска при запуске. Если файла нет,
берётся встроенная копия.

### 7.4 Основные типы

| Тип | Что это |
|---|---|
| `BlockId`, `ItemId` | индексы в реестре (на один запуск); `BlockId::k("key")` — по ключу |
| `Cell { id, facing }` | содержимое клетки; `facing` 0..5 = +X −X +Y −Y +Z −Z |
| `VoxelGrid` | компонент сетки: `get`, `set`, `cells`, `raycast`, `entities` (клетка → сущность механизма) |
| `BlockEntity { grid, cell, id, facing }` | сущность механизма |
| `Params` | значения настроек; `get(id, "key")` |
| `Signal(f32)` | входящий сигнал −1..1, сбрасывается каждый кадр |
| `Spin { rpm, angle }` | обороты и угол |
| `Contraption { mass }` | метка физической сетки |
| `Glue(Vec<(IVec3, IVec3)>)` | склеенные объёмы сетки |
| `Linked(Option<PanelRef>)` | пульт, который слушает датчик, или экран, на который пишет датчик телеметрии |
| `Shown(f32)` | значение, пришедшее на экран в этом кадре |
| `Headlight { on }` | состояние фары |
| `Schematic` | чертёж: блоки (клетка, ключ, поворот, настройки), связи, клей |
| `Sfx { name, at, volume }` | сообщение: проиграть звук |
| `NetState { driven, .. }` | сеть блока: есть ли в ней источник (тормоз колёс) |
| `Ui` | состояние: Game, Inventory, Console, Debug, Settings |
| `UseBlock` | сообщение: ПКМ по блоку с действием (сиденье, переключатель) |
| `Toast` | короткое сообщение на экране |

### 7.5 Как добавить

- **Строительный блок.**
  1. Строка в `blocks.ron` с `textures`.
  2. PNG 32×32 в `assets/textures/`: нарисовать вручную или добавить функцию
     в `tools/texgen/texgen.py` и словарь `TEXTURES`.
  3. Блок сам появится в каталоге, с иконкой, мешем и коллизией.
- **Механизм.**
  1. Вариант в `enum Mech` (`content.rs`) и строка в `blocks.ron` с `mech`.
  2. Модель в `models::block_model`. Детали со слоем `Rotor` крутятся,
     `Steer` поворачиваются рулём.
  3. Если он участвует во вращении — узел в `mech::node_for`. Роли: `Shaft`,
     `Cog`, `LargeCog`, `Gearbox`, `Clutch`, `Gearshift`; `one_port` — выход
     только с одной стороны; `source` — источник.
  4. Своё поведение — система в своём модуле, читающая `BlockEntity`,
     `Params`, `Signal`, `Spin`.
- **Реакция на сигнал.** Блок получает `Signal` от датчика автоматически;
  достаточно читать `Signal.0` в его системе (или в `node_for`).
- **Настройка блока.** Добавить в `params`. Окно гаечного ключа строится само.
- **Инструмент.** Строка в `tools.ron`, вариант в `enum Tool`, модель в
  `models::tool_model`, обработчик в `src/tools/`. Он читает
  `interact::Clicks` и `Target` и работает, когда `held_tool(inv)` равен
  нужному инструменту.
- **Команда консоли.** Ветка в `debug::run_command`.
- **Новая возможность целиком.** Свой модуль с `Plugin` и подключение в `main.rs`.

### 7.6 Тесты

**Юнит-тесты** (`cargo test`, 72 штуки) проверяют:
- загрузку контента и наличие всех текстур;
- сетку, raycast, повороты;
- мешер и слияние коллизий, формы плит и скосов (меш и коллайдер);
- решатель сети (валы, шестерни, коробка, муфта, реверс, конфликт, предел,
  есть ли в сети источник);
- экран, который крутит шестерня сбоку;
- телеметрию: что читает датчик, цепочку «спидометр / мотор → датчик →
  экран» через настоящую систему чтения и обнуление при остановке, стрелку
  без питания, 7-сегментные цифры;
- фару (каждое нажатие переключает);
- чертежи: поворот, копия только с внутренними связями, сохранение и
  загрузка;
- раскладку полигона;
- настройки мотора и регулятора;
- инвентарь, правила установки, клей и выравнивание поворота;
- сигналы клавиш, фильтр каталога, время суток;
- подшипник и поршень (шаги поворота и хода);
- жидкости: объединение цистерн и объём в mB, оседание вниз, одна жидкость
  в баке, помпа от кинетической сети перекачивает между двумя цистернами;
- дизель (топливо, воздух), плавучесть по Архимеду;
- логику: соединение проводов по цвету и через ребро, распространение
  сигнала, элементы И/ИЛИ/НЕ/RS, мигалку;
- нагрузку: SU цепи валов и шестерён, замедление при перегрузке, редуктор
  вдвое снижает нагрузку, нагрузку колёс на подъёме, загрузку на экране;
- настройки игры (шаги, сохранение и загрузка);
- подсказки: у каждого видимого предмета есть описание; сцены «Как
  работает» используют настоящие блоки и настройки;
- запрет большой шестерни вплотную к малой;
- редактор текстур: кисть, заливка до границы, отмена, пипетка, оттенки;
- модели Blockbench: размеры и слои, кости игрока, экспорт → импорт
  каждого встроенного механизма без потерь;
- выбор самой новой сборки из списка релизов GitHub.

**Автотест** (`--autotest`, 149 проверок) играет в настоящую игру через те же
ресурсы ввода и снимает экран. Этапы (`AUTOTEST_ONLY=этап,этап`):

| Этап | Что проверяет |
|---|---|
| `basics` | полигон и разметка; ходьба и бег; присед у края; двойной пробел; ломать / ставить / брать блок; инвентарь, каталог и поиск; меню F3 и консоль; модель игрока |
| `mech` | мотор, валы, коробка, шестерни; связь пульта и датчика ключом; сиденье; муфта, реверс и регулятор по клавише с пульта; стенд телеметрии (цифры и стрелка, без питания гаснет); поворот ключом и окно настроек |
| `car` | машина в блоках со спидометром и экраном; переключатель физики; масса; машина стоит на пружинах; связь телеметрии ключом; сесть, ехать на W — экран показывает скорость, переключить на стрелку, рулить A, остановка; возврат в блоки |
| `guns` | клей двумя щелчками; физическим становится только склеенное; физпушка (схватить, поднять, заморозить, разморозить); гравипушка (толкнуть, притянуть) |
| `build2` | подъём пешком по скосу 14°; фара переключается каждым нажатием (ночной снимок); чертёж: копия, голограмма, поворот, вставка, `save` / `load` |
| `ground` | общий вид полигона; машина проезжает все пять дорожек (эстакады 15° и 30°, скосы 27° и 14° — заезд на плато; «гребёнка» — без опрокидывания) |
| `mounts` | подшипник в мире; поршень выдвигает и втягивает; кран на физической машине и возврат в блоки |
| `fluids` | дизель через порт и трубу запускает двигатель, расход, глохнет без воздуха; помпа перекачивает туда и обратно; плот плывёт, подлодка набирает балласт и тонет |
| `logic` | рычаг → красный провод → мигалка, синий рядом не соединяется; таймер; мигание; элемент НЕ управляет муфтой; перекраска ключом |
| `menu` | главное меню, настройки применяются сразу, пауза останавливает мир; подсказка в инвентаре и «Как работает» коробки передач; редактор текстур (мазок сразу в атласе блоков, сохранение PNG, отмена); масштаб рендера 60 % и обратно |
| `torque` | тяжёлая машина на дизеле: на эстакаде 30° на прямой передаче глохнет, с редуктором заезжает |
| `links` | цепь инструментом через три шестерни (одна сторона и крест-накрест); лента между валами, игрок едет на ней; лента 45°; машина на гусеницах |
| `shapes` | все формы всех материалов, установка ступеньки; раздвижная дверь (ПКМ и рычаг); инженерные очки и слоты экипировки; витрина: колесо у подвески, зацепление шестерён, обе коробки передач |
| `icons` | атлас иконок |

### 7.8 Сборка для macOS и обновления

**Как это работает.** Каждый push, который меняет `Sandbox/`, запускает
`.github/workflows/sandbox.yml`:
1. юнит-тесты на Linux;
2. на macOS (Apple Silicon) — `cargo build --release`, затем
   `tools/macos/make_app.sh` собирает `Sandbox.app` (иконка, Info.plist,
   ad-hoc подпись) и `Sandbox-macOS.zip`;
3. публикуется релиз `sandbox-b<N>` (N — номер запуска) с этим архивом.

Номер сборки зашит в программу (`SANDBOX_BUILD`). Главное меню спрашивает у
GitHub список релизов и, если есть номер больше, показывает «Обновить»:
игра скачивает архив (`curl`), распаковывает (`ditto`), подменяет
`Sandbox.app` на месте и предлагает «Перезапустить». Ваши файлы —
настройки, чертежи, текстуры, модели — лежат в
`~/Library/Application Support/Sandbox` и при обновлении не трогаются.
Ваша копия файла из `assets/` (например, отредактированная текстура)
важнее встроенной.

**Первая установка** (один раз):
1. GitHub → Releases → последняя `Sandbox — сборка N` → скачать
   `Sandbox-macOS.zip`, распаковать.
2. Перетащить `Sandbox.app` в «Программы».
3. Приложение не заверено Apple, поэтому при первом запуске macOS его
   заблокирует. Откройте «Системные настройки → Конфиденциальность и
   безопасность» → внизу «Всё равно открыть». Или в Терминале:
   `xattr -dr com.apple.quarantine /Applications/Sandbox.app`.

Дальше обновления ставятся из игры, без этих шагов: файлы, скачанные
самой игрой, macOS не помечает.

- Сборка только для Apple Silicon (M1 и новее).
- Если приложение запущено прямо из «Загрузок», macOS запускает его копию
  только для чтения — обновление попросит перенести его в «Программы».
- В разработке (`cargo run`) обновления выключены: файлы берутся из папки
  проекта, как раньше.
