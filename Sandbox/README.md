# Sandbox

Воксельная физическая песочница в духе Garry's Mod / Minecraft / Hytale на
**Rust + Bevy 0.20 + Avian 0.8**. Пока только творческий режим: строить из
блоков, собирать механизмы как в моде Create, превращать склеенные постройки
в физические тела и ездить на них, двигать объекты гравипушкой и физпушкой,
выводить скорость на механические экраны, копировать постройки чертежами,
испытывать машины на инженерном полигоне, строить краны на подшипниках и
поршнях, проводить жидкости и дизель по трубам, спускать на воду подлодки с
балластом, собирать схемы из проводов и логики. Начинается с главного меню;
Esc — пауза и настройки (графика, звук, управление).

**Установить на Mac:** GitHub → Releases → последняя «Sandbox — сборка N» →
`Sandbox-macOS.zip` → `Sandbox.app` в «Программы»; при первом запуске
«Системные настройки → Конфиденциальность и безопасность → Всё равно
открыть». Дальше обновления — кнопкой «Обновить» в главном меню
(`docs/GAME_GUIDE.md`, 7.8).

Отдельный проект; часть решений взята из Aetherwright, но всё лишнее убрано.

## Запуск

```bash
cargo run --release
# сценарий-автотест со снимками экрана (выход 0 — всё прошло):
cargo run -- --autotest --shots shots
# только отдельные этапы автотеста: basics, mech, car, guns, build2, ground,
# mounts, fluids, logic, menu, torque, links, shapes, icons
AUTOTEST_ONLY=car cargo run -- --autotest --shots shots
cargo test                              # юнит-тесты
python3 tools/texgen/texgen.py          # пересоздать текстуры (нужны numpy, Pillow)
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD, мышь | ходьба, взгляд |
| Ctrl | бег |
| Shift | присесть — с края блока не упасть; в полёте вниз; на сиденье — встать |
| Пробел | прыжок; два раза быстро — полёт вкл/выкл; в полёте вверх |
| ЛКМ / ПКМ / СКМ | сломать / поставить / взять блок в хотбар |
| ПКМ по сиденью или переключателю физики | сесть / дать или забрать физику (Shift+ПКМ — поставить блок) |
| 1–9, колесо | слот хотбара |
| E | инвентарь; кнопка «Все предметы» — каталог и обратно |
| F5 | вид: от первого лица / сзади / спереди |
| F3 | меню отладки (время: стоп/пуск, утро/день/вечер/ночь, скорость) |
| T или / | консоль (`help`) |
| Esc | в игре — пауза (продолжить, настройки, текстуры, в меню, выход); в окне — закрыть |
| наведение / Shift / удерживать W | в инвентаре: кратко / подробно / «Как работает» — сцена по шагам |

**Инструменты**

| Инструмент | ЛКМ | ПКМ | Ещё |
|---|---|---|---|
| Гаечный ключ | настройки блока; по пульту, затем по датчику — связать их; по датчику телеметрии, затем по экрану — связать их | повернуть блок на 90° вокруг грани | |
| Клей | первый угол, второй угол — склеить всё в этом объёме | снять клей с области | области видны, пока клей в руке |
| Гравитационная пушка | толкнуть (или выбросить удерживаемое) | притянуть и держать / отпустить | тяжелее 1,5 т — только толкать |
| Физическая пушка | держать — схватить и вести за прицелом | заморозить в воздухе | колесо — ближе/дальше, E + мышь — вращать, R — разморозить |
| Чертёж | скопировать склеенную группу или конструкцию | поставить копию | голограмма (красная — место занято), R — поворот на 90° |
| Ведро дизеля | | по заливному порту: +1000 mB | не кончается |
| Провод (в руке) | | проложить по грани блока | Shift + колесо — цвет (8 цветов); ЛКМ ключом — перекрасить |
| Медный / стальной корпус (в руке) | | по валу или трубе — надеть кожух | Shift + ПКМ ключом — снять |

**Консоль**: `time set <часы|morning|day|evening|night>`, `time stop`,
`time start`, `time speed <×>`, `tp x y z`, `fly`, `give <ключ> [n]`,
`clear`, `save <имя>` / `load <имя>` (именованные чертежи в `schematics/`),
`blueprints` (список), `model export <ключ|player>` (модель в Blockbench), `help`.

## Что есть

* Мир — инженерный полигон 128 × 128 в пустоте: тёмный бетон, разметка
  по чанкам 16 × 16, на западном краю пять испытательных дорожек (гладкие
  эстакады 15° и 30°, скосы из блоков 27° и 14°, «гребёнка»). Синее небо,
  смена дня и ночи (сутки = 20 минут).
* Игрок размером и формой как в Minecraft, без скина; анимации ходьбы, бега,
  приседания, сидения и взмаха руки; приседая, не падает с края.
* Хотбар 9, инвентарь 6 × 9, каталог всех предметов: категории слева,
  прокрутка, поиск внизу. Иконки снимаются с настоящих 3D-моделей.
* Механизмы (`docs/MECHANICS.md`): креативный мотор, вал, шестерня, большая
  шестерня, коробка передач, муфта, реверс, регулятор скорости, подвеска,
  колесо, сиденье, пульт, датчик, переключатель физики; спидометр, датчик
  телеметрии, механический экран (цифры или стрелка, питание вращением
  сбоку), фара (каждое нажатие — вкл/выкл).
* Стальная плита и скосы 45°, 27° и 14° — с настоящей формой коллизии.
* Механический подшипник и поршень: подвижная часть — отдельное тело на
  шарнире Avian, в мире и на физической машине (кран).
* Жидкости (mB; ведро 1000, блок цистерны 16 000): цистерны объединяются в
  линию 1×N и колонны 1×1/2×2/3×3, трубы и трубы в кожухе, помпа
  (|об/мин| × 8 mB/с), заливной порт, ведро дизеля.
* Дизельный двигатель: 10 mB/с дизеля, нужен воздух над выхлопом, дым и звук.
* Бассейн 32 × 32 × 10 со спуском, плавание, плавучесть по Архимеду,
  балластные цистерны для подлодок.
* Мощность и нагрузка (SU, как в Create): дизель 2048 SU, мотор 16 384;
  колёса тяжёлой машины на подъёме нагружают двигатель, при перегрузке сеть
  замедляется, дизель глохнет — нужны понижающие передачи; маховик.
* Формы для всех строительных материалов (плита, ступенька, скос,
  внешний/внутренний угол — Shift + колесо), раздвижные двери.
* Цепи между шестернями (сверху/снизу, под углом, цепочкой), механические
  ленты между валами (прямо, вертикально, 45°; везут игрока и тела),
  модульные гусеницы (звёздочка + катки).
* Слоты экипировки (голова, тело, ноги, обувь) и инженерные очки с данными
  блоков у прицела.
* Логика: провода на любой грани (8 цветов, разные не соединяются), кнопка,
  рычаг, таймер, генератор импульсов, элементы И/ИЛИ/НЕ/RS, мигалка, лампа,
  пороговый датчик (механика → сигнал), радиопередатчик и приёмник (16
  каналов, без проводов).
* Подсказки у каждого предмета и «Как работает» для механизмов (как Ponder
  в Create): удерживать W над предметом в инвентаре.
* Редактор текстур в игре и свои модели блоков и игрока из Blockbench —
  `docs/MODDING.md`.
* Вид в духе Minecraft / Hytale: затенение граней, блочные облака, дымка у
  горизонта; масштаб рендера 50–100 % для Retina.
* Звуки (CC0, `assets/sounds/CREDITS.md`): блоки, инструменты, интерфейс,
  гул моторов.
* Механизмы работают одинаково и в блоках, и в физическом теле.

## Устройство

Каждая возможность — отдельный плагин Bevy (`src/main.rs`).

| Модуль | Что делает |
|---|---|
| `content` | реестр категорий, блоков, инструментов из `assets/content/*.ron` |
| `grid` | воксельные сетки (мир и конструкции), мешер с AO, коллайдеры, атлас |
| `world`, `sky` | платформа; время суток, солнце, небо |
| `player` | движение, камера, модель и анимации |
| `interact`, `inventory`, `ui`, `icons` | прицел и правка блоков; инвентарь; интерфейс; иконки |
| `mech` | блоки-сущности, настройки, кинетическая сеть (`mech/network.rs`) |
| `signal`, `vehicle` | пульт → датчики → блоки; сиденья и руление |
| `contraption` | клей + переключатель → физическое тело; подвеска и привод колёс |
| `telemetry`, `lights`, `sound` | телеметрия и экраны; фары; звуки |
| `assembly`, `mounts` | отделение и слияние сеток; подшипник и поршень |
| `fluids`, `engine`, `water` | жидкости; дизель; бассейн и плавучесть |
| `logic` | провода и логические блоки |
| `menu` | главное меню, пауза, настройки (`settings.ron`) |
| `chains`, `belts`, `tracks` | цепи, механические ленты, гусеницы |
| `doors`, `goggles` | раздвижные двери; инженерные очки |
| `tools` | ключ, клей, гравипушка, физпушка, чертежи, предмет в руке |
| `settings`, `debug` | окно настроек блока; меню F3 и консоль |
| `models`, `style` | модели из «пиксельных брусков», материалы, стиль |
| `ponder`, `paint`, `bbmodel` | «Как работает»; редактор текстур; модели Blockbench |
| `paths`, `update` | где лежат файлы; обновление из релизов GitHub |
| `autotest` | сценарий-автотест |

### Как добавить

* **Строительный блок** — строка в `assets/content/blocks.ron` с текстурами
  `(верх, бока, низ)` + PNG 32×32 в `assets/textures/` (или функция в
  `tools/texgen/texgen.py`). Блок сразу появится в каталоге со своей иконкой.
* **Механизм** — строка в `blocks.ron` с `mech: Some(…)`, модель в
  `src/models.rs`, поведение — в `mech::node_for` (кинетика) или своём модуле.
* **Настройка блока** — `params` в `blocks.ron` (число, выбор, клавиша);
  окно ключа строится само, значение читается `Params::get(id, "ключ")`.
* **Категория** — `assets/content/categories.ron`; **инструмент** —
  `assets/content/tools.ron` + обработчик в `src/tools/`.

Полное описание игры (все блоки и предметы, механики, стиль, устройство, документация) — `docs/GAME_GUIDE.md`. Стиль — `docs/STYLE.md`. Свои текстуры и модели — `docs/MODDING.md`.
