# Электросеть (V2)

Пять звеньев из задания разделены: **источник → передача → хранение →
преобразование → потребление**.

| Звено | Что это в игре |
|---|---|
| Источник | эфирная динамо-машина (из магии), электрогенератор на валу (из вращения) |
| Передача | медный провод (12 Вт, потери 1,2 %/м, до 10 м), силовой кабель (60 Вт, 0,4 %/м, до 16 м), внутренняя шина сварной/шарнирной конструкции |
| Хранение | энергоячейка: запас 1000, но отдача и заряд не больше 30 Вт |
| Преобразование | генератор (вращение → электричество), мотор (электричество → вращение), динамо (эфир → электричество) |
| Потребление | двигатель (физический), электромотор (кинетическая сеть) |

## Как считается

Каждый физический такт (`electric/network.rs`, чистая функция с тестами):

1. генерация → потребители;
2. накопители (с учётом предела отдачи) → оставшиеся потребители;
3. излишек генерации → зарядка накопителей.

Каждый шаг — поиск максимального потока по графу: провод пропускает не
больше своей ёмкости, мощность теряется пропорционально длине каждого
пройденного провода, поэтому далёкий потребитель обходится дороже.
У каждого потребителя есть «удовлетворённость» 0…1: меньше половины — двигатель
и мотор не работают.

* **Большой запас ≠ большая мощность**: ячейка с полным зарядом всё равно
  отдаёт не больше 30 Вт.
* **Перегрузка**: провод на пределе нагревается; через 8 с непрерывной
  перегрузки **перегорает** (исчезает), потребители без него обесточиваются.
  Остывает вдвое медленнее, чем греется.
* **Нет бесплатной энергии**: динамо копит выработку в маленьком буфере
  (8 единиц) — если сеть её не забирает, лишнее теряется.

## Виды связей разделены

* **Провод** — только энергия.
* **Сварка / шарнир** — сила (физика) и, как внутренняя шина, энергия внутри
  одной конструкции (двигатель, приваренный к ячейке, работает как раньше).
* **Сигналы** — отдельный вид связи на этапе V4.

## Инструмент

Провод или кабель в руке: **ЛКМ** по первому устройству (или детали), затем по
второму — проложить (стоимость — 1 провод на каждые 4 м). **ПКМ** по устройству —
снять все его провода (возвращаются). Слишком длинный пролёт не прокладывается.
**F6** — оверлей: голубой — ток есть, жёлтый — нагрузка > 70 %, красный —
перегрузка, серый — тока нет.

## Сохранения

Провода хранятся в расширении `wires`: концы — номер детали в файле
сохранения или клетка кинетического блока. Расширения восстанавливаются
после деталей и соединений, поэтому ссылки разрешаются.

## Ограничения

* Провода — прямые отрезки без провисания и без столкновений.
* Сеть пересчитывается каждый физический такт целиком: для сотен устройств
  этого хватает; для тысяч — разбиение на активные и удалённые сети (план).
* Числа временные (баланс — открытый вопрос концепта).
