# Руководство по стилю

Общий визуальный стиль игры: всё новое делается сразу в нём. Референсы —
`docs/references/style/` (а также `docs/references/` и `ART_DIRECTION.md`).
Ничего не копируется из других игр: текстуры и модели — свои, «в духе».

| Направление | На что похоже | Где в игре |
|---|---|---|
| Мир, блоки, природа | Hytale: сочный, насыщенный, «рисованный» | `assets/textures/blocks/` |
| Механизмы | Create: андезит, латунь, медь, дерево, рамки, болты | `assets/textures/materials/`, модели в `kinetics::model` |
| Магия | Thaumcraft: тёмный рунический камень, золото, светящиеся кристаллы, ауры и искры | те же места + `arcana` (искры) |

## 1. Пиксели и масштаб

* Текстуры **32 × 32** на блок (1 метр). Всё — `nearest`, без размытия.
* **Одна плотность пикселей везде**: модели механизмов собираются из
  «пиксельных брусков» (`style::pixel_box`) — текстура ложится 32 пикселя на
  метр, поэтому зуб шестерни 0,25 м показывает 8 пикселей, как в Create.
* Формы — крупные, читаемые, «коренастые»: детали не тоньше 0,06 м.

## 2. Палитры (в `tools/texgen/texgen.py`)

Каждый материал — **4–6 оттенков**, переход ступенчатый (не градиент).

* Трава `#2e6a2b → #84ca55`, земля `#4a2e1d → #a37645`, камень холодный
  серо-синий `#474b55 → #a1a7b0`, песок тёплый, листва сочная тёмно-зелёная.
* Андезит `#5c615e → #b2b7b0`, латунь `#7a5520 → #f7d88a`, медь
  `#6a3220 → #e8996a`, дерево механизмов `#5e3b1f → #c79559`.
* Рунический камень `#15141c → #524c66`, золото `#6b4a12 → #fff0a8`,
  кристалл `#1a4e78 → #d9fbff`, поток/искажение `#2a0f3a → #e5a8ff`.

## 3. Объём и свет

* Внутри текстуры: свет сверху-слева, тень снизу-справа; у блока мягкая
  фаска по краю (светлый верх, тёмный низ). Камни, руда и гравий — с тёмной
  обводкой «трещин».
* В мире: тёплое дневное солнце, голубое небо, светлая заливка, окклюзия по
  вершинам в мешере.
* **Свечение только у магии и индикаторов**: неосвещаемые материалы с цветом
  ярче 1.0 (HDR) дают ореол (bloom); руны светятся только по самим линиям
  (`arcane_rune_glow` — маска свечения).
* Тональная коррекция TonyMcMapface — сохраняет насыщенность.

## 4. Механизмы (Create)

* Корпус: рамка из андезита / латуни / меди с болтами по углам, внутри —
  доски (`*_casing`).
* Валы — андезитовые бруски 0,22 м; шестерни — деревянный диск-восьмиугольник
  с крупными зубьями-брусками и андезитовой ступицей.
* Электрика — медь с латунными кольцами; логика — андезитовое основание,
  латунный или медный корпус, зелёный индикатор, кристальная линза датчика.
* Движение видно: всё вращающееся вращается (обороты × время).

## 5. Магия (Thaumcraft)

* Пьедестал: рунический камень + золотая лента + колонна с рунами.
* Сверху — фокус: парящая сфера-аура с ореолом, кристальная банка со
  светящимся ядром, вращающиеся золотые кольца, кристальные наконечники.
* Магия «дышит»: фокусы парят и пульсируют, заполненные устройства
  испускают искры цвета своего вида магии (не больше 240 одновременно).
* Цвета видов: естественная — бирюза, раздражённая — пурпур,
  конденсированная, древняя и уникальная — по `AetherKind::rgb`.

## 6. Как добавить новое в стиле

1. **Текстура блока или материала**: функция в `tools/texgen/texgen.py` из
   готовых приёмов (`stone_like`, `ore`, `crystal`, `casing`, `plate`) с
   палитрой из раздела 2 → `python3 tools/texgen/texgen.py` → PNG в
   `assets/textures/`. Дорисовать вручную — F7 или любой редактор
   (горячая перезагрузка).
2. **Модель механизма**: описание из брусков в `kinetics::model` —
   `part(bx(…), "andesite_casing", позиция, слой)`; слой — корпус, ротор,
   ядро, парение или вращение.
3. **Сложная модель** (существо, персонаж): Blender → `.glb`
   (`docs/MODELS_AND_ANIMATION.md`), те же палитры, крупные формы.
4. Проверить: `cargo run -- --showcase --screenshots shots` — витрина стиля
   (блоки, механизмы, магия, логика) снимается с пяти ракурсов.

## 7. Ограничения сейчас

* Персонаж и существа — ещё простые фигуры (следующий шаг стиля: модели
  в Blender по этому руководству).
* Небо — сплошной цвет без облаков; иконки предметов — цветные плашки.
