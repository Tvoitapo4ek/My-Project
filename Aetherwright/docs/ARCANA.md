# Магический конвейер (V3)

Цикл из задания: **источник → сбор → обработка → стабилизация → хранение →
передача → потребитель**. Магия — не одно число.

## Параметры магии

У каждого устройства внутри:

| Параметр | Смысл |
|---|---|
| количество / ёмкость | сколько эфира внутри |
| вид | естественная, раздражённая, конденсированная, древняя, уникальная — **не смешиваются** |
| стабильность 0–1 | от неё зависит, какую долю мощности даст магический двигатель |
| искажение 0–1 | устройства не принимают магию сильнее искажённую, чем выдерживают |

Скорость поступления, мощность и пропускная способность — у источников,
двигателей и связей. Совместимость — по виду, по рунам и по искажению.

Сырой вид из источника (временные числа): естественная — стабильность 0,9,
искажение 0,05; раздражённая — 0,35 / 0,6; конденсированная — 0,5 / 0,45;
древняя — 1,0 / 0; уникальная — 0,2 / 0,85.

## Устройства (`content/arcana.ron`)

| Устройство | Роль |
|---|---|
| Коллектор эфира | собирает магию из поля вокруг (фоновая магия есть везде, у кристаллов — сильнее); вид — как у ближайших источников |
| Магический фильтр | пропускает только вид, заданный руной «Фильтр» |
| Стабилизатор | снимает искажение и повышает стабильность; **нужна электроэнергия** (4 Вт, провод из V2) |
| Кристаллический накопитель | хранит до 120 одного вида |
| Резонатор-передатчик / приёмник | беспроводная передача |
| Магический двигатель | источник вращения **кинетической сети** (V1); мощность = доля полученного эфира × стабильность; не принимает искажение выше 0,3 |

Эфирные накопители-банки (физические детали) тоже участвуют как хранилища.

## Три способа передачи (гибрид из концепта)

| Способ | Как | Ограничения |
|---|---|---|
| Кристаллический проводник | физическая связь, в обе стороны | 3/с, потери 1 %/м, до 8 м; надёжный |
| Рунический канал (рунный резец) | от первого устройства ко второму | 2/с, 0,5 %/м, до 20 м; **нужна прямая видимость** — стена прерывает канал |
| Резонанс | передатчик → все приёмники той же частоты в 32 м | всего 1,2/с на всех; потери 2 %/м; помеха +искажение, а каждый чужой передатчик той же частоты рядом добавляет ещё |

Беспроводная передача не делает проводники лишними: она слабая, теряет на
расстоянии и портит качество магии.

## Руны

Руна — предмет; с руной в руке **ПКМ** по магическому устройству — нанести (до
трёх). В режиме «Механизмы» **ЛКМ / ПКМ** меняют значение первой / второй руны.
Разборка устройства возвращает руны.

| Руна | Влияние |
|---|---|
| Фильтр | принимать только выбранный вид |
| Ограничение | отток 25 / 50 / 75 / 100 % от 2/с |
| Направление | только отдаёт / только принимает |
| Связь | частота резонатора 1–8 |

Это расширяемая основа: полная рунная логика — открытый вопрос концепта,
универсальный язык программирования не делается без согласования.

## Как считается

`arcana/network.rs` — чистая функция с тестами, каждый физический такт:

1. приток коллекторов;
2. перетекание от более заполненного к менее заполненному, в пределах
   пропускной способности и с потерями; отказ при несовместимости
   (вид, руна, искажение, направление); помехи связи;
3. стабилизаторы;
4. потребители.

## Интеграция

* **Электричество → магия**: стабилизатор питается от электросети.
* **Магия → механика**: магический двигатель вращает вал; вал крутит
  дробилку или электрогенератор (замкнутые цепочки возможны, но с потерями
  на каждом звене — бесплатной энергии нет).
* Инженерная панель показывает эфир, вид, стабильность, искажение, руны,
  связи и причины отказа; сохранение — расширение `arcana`.

## Ограничения

* Эффекты аномалий на магию (помехи от раздражённых полей) — этап V6.
* Нестабильность пока снижает мощность, но не вызывает аварий (V5).
* Модели устройств — простые фигуры с цветом и светящимся ядром.
