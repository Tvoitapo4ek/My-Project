# Логика и автоматизация (V4)

Автоматизация без программирования. Три вида взаимодействия разделены
(задание §13):

| Вид | Чем передаётся |
|---|---|
| Физическое | соединения, валы, шестерни (кинетическая сеть) |
| Энергетическое | провода (электросеть), магические связи |
| **Информационное** | **сигнальные кабели и радиоканалы** |

## Сигнал

Число 0…1; больше 0,5 — «включено». Каждый физический такт каждый элемент
вычисляет выход по входам прошлого такта (`logic/circuit.rs`, чистая функция
с тестами). Задержка в один такт на элемент делает обратные связи
(защёлки, генераторы) устойчивыми и предсказуемыми — как у реле.

## Элементы (`content/logic.ron`)

| Элемент | Поведение | Настройка («Механизмы») |
|---|---|---|
| Датчик оборотов | обороты соседнего вала / 256 | — |
| Датчик заряда | заряд сети ближайшего устройства | — |
| Датчик эфира | заполненность соседнего магического устройства | — |
| Датчик искажения | искажение магии в соседнем устройстве | — |
| Датчик присутствия | 1, если в 4 м игрок или существо | — |
| Кнопка | импульс на 1 с | ЛКМ — нажать |
| Рычаг | вкл / выкл | ЛКМ — переключить |
| Таймер | импульс раз в 1/2/5/10 с | ЛКМ — период |
| Счётчик | включается на 2/4/8/16-м импульсе | ЛКМ — цель |
| И, ИЛИ, НЕ, исключающее ИЛИ | логика входов | — |
| Компаратор | вход больше / меньше порога 0,1…0,9 | ЛКМ — порог, ПКМ — больше/меньше |
| Контроллер | команды механизму | ПКМ — по сигналу / наоборот / переключать по импульсу |
| Передатчик / приёмник | радиоканал 1–8 без проводов | ЛКМ — канал |
| Индикатор | горит, когда вход включён | — |

Ядро любого элемента **светится**, когда его выход включён.

## Кабели

Сигнальный кабель в руке: **ЛКМ** по источнику, затем по получателю
(направленный, до 16 м). **ПКМ** — снять кабели устройства.

* Логика → логика — сигнал.
* **Устройство → датчик — телеметрия**: датчик читает именно это устройство
  (иначе — соседей).
* **Логика → механизм — команды**: электромотор и магический двигатель
  включаются, физический двигатель включается, муфта соединяется, реверс
  разворачивает. Пока есть командный кабель, механизм слушается его (ручное
  переключение перезапишется сигналом).

## Пример (из автотеста)

Датчик эфира на кристаллическом накопителе → компаратор «больше 0,3» →
контроллер → магический двигатель. Запаса много — двигатель крутит вал и
дробилку; запас кончился — контроллер выключает двигатель.

## Диагностика

**F6** — стрелки сигналов (ярче — включено). Инженерная панель показывает
выход элемента, настройку, число входов и выходов, полученную механизмом
команду и предупреждение «нет входного сигнала».

## Ограничения

* Команды пока только для моторов, двигателей, муфт и реверсов; станции
  (дробилка, плавильня) и стабилизатор — следующий шаг.
* Нет «программ» и произвольных выражений — по заданию, только визуальные
  элементы.
