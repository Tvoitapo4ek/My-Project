# Aetherwright — First Playable

Оригинальная 3D voxel sandbox-игра об исследовании, инженерии и магии.
Rust + **Bevy 0.20.1** + **Avian 0.8.0** (физика).

## Требования

* Rust **1.97.1** — зафиксирован в `rust-toolchain.toml`, rustup поставит сам.
* macOS (Apple Silicon) — основная платформа; Linux и Windows тоже собираются
  (CI: `.github/workflows/aetherwright.yml`, раннеры macOS / Ubuntu / Windows).
* Linux: `sudo apt install libasound2-dev libudev-dev libwayland-dev libxkbcommon-dev`.

## Сборка и запуск

```bash
cd Aetherwright
cargo run --release                 # игра (выживание)
cargo run --release -- --creative   # сразу в креативе
cargo test                          # юнит-тесты
./run_autotest.sh [папка_скриншотов]  # сквозной сценарий в настоящей игре
```

Отладочная сборка (`cargo run`) тоже играбельна: зависимости собираются с
`opt-level = 3`. Для быстрой итерации: `cargo run --features dev`
(динамическая линковка Bevy).

Сохранения: `saves/world.json` (+ `world.json.bak`); каталог можно задать
переменной `AETHERWRIGHT_SAVE_DIR`. Настройки: `assets/config/game.json`
(необязательный, любые поля `GameConfig`, см. `src/core/config.rs`).

## Управление

| Клавиша | Действие |
|---|---|
| WASD, Shift, Ctrl, Space | ходьба, бег, присесть, прыжок / всплыть |
| Мышь | обзор; V — 1-е/3-е лицо; Alt + колесо — дистанция камеры |
| 1–9, колесо | быстрые слоты |
| ЛКМ / ПКМ | действие инструмента (см. ниже) |
| Q | режим инструмента (манипулятор, гравизахват, фокус) |
| E | подобрать предметы рядом / попить, глядя на воду |
| G | выбросить предмет; P — автоподбор вкл/выкл |
| Tab | голографическое устройство (инвентарь, сборка, экипировка, карта, журнал, чертежи, персонаж, настройки) — см. `docs/HOLO_UI.md` |
| I / J / N | устройство сразу на инвентаре / журнале / карте |
| B | меню строительства |
| R / Shift+R | повернуть / наклонить размещаемую деталь; R + мышь — вращать удерживаемый объект |
| M | выживание ⇄ креатив |
| F (креатив) | полёт |
| F1 / F3 / F4 / F6 | скрыть HUD / отладка / отладка физики / оверлей сетей (вращение, провода, сигналы) |
| F7 | редактор текстур блоков |
| F5 / F9 | сохранить / загрузить |
| Esc | пауза (при открытом устройстве — закрыть его) |

**Манипулятор** (Q): *Добыча* — удерживать ЛКМ (по объекту — забрать его);
*Сканирование* — ЛКМ; *Резка* — вырезать блок физическим телом (модуль резки);
*Механизмы* — ЛКМ вкл/выкл двигатель, ПКМ тяга/реверс, ЛКМ по станции —
её интерфейс, по ящику — забрать содержимое; *Выделение* — два угла ЛКМ,
C копировать, X вырезать, Delete удалить, T повернуть, V вставка (R поворот,
ПКМ построить), Enter (креатив) — заполнить.
С блоком в руке: ПКМ — поставить, ЛКМ — добывать. С модулем — ПКМ установить.

**Гравизахват** (Q): *Захват* (держать ЛКМ, колесо — дистанция, ПКМ — заморозить),
*Сварка* / *Шарнир* (ЛКМ по детали, затем по основанию), *Разъединение*.

**Эфирный фокус** (Q): Импульс, Левитация, Разряд — ЛКМ.

Креатив: `[` `]` время суток, `\` остановить время, `-` `=` `0` гравитация.

## Как собрать первую машину

1. Поставьте **двигатель** (ПКМ с ним в руке), рядом — **раму**, вплотную к грани +X.
2. Положите 4 **колеса**. Гравизахват → *Шарнир*: ЛКМ по верхней грани колеса,
   затем по боковой грани двигателя (два ведущих колеса) или рамы (два свободных).
3. Поставьте **энергоячейку** на двигатель; гравизахват → *Сварка*: ячейка → двигатель,
   рама → двигатель.
4. Манипулятор → *Механизмы* → ЛКМ по двигателю. Машина поедет.

## Моддинг, текстуры, модели

* Блоки, текстуры, предметы, рецепты — в `assets/content/*.ron`; моды — в
  `mods/<имя>/…`. Подробно: `docs/MODDING.md`.
* Текстуры блоков — PNG в `assets/textures/blocks/`; правка во внешнем
  редакторе подхватывается на лету; встроенный редактор — `F7`.
* 3D-модели и анимации (Blender → glTF): `docs/MODELS_AND_ANIMATION.md`.
* План развития: `docs/ROADMAP.md`.
