СПИСОК ДЕЛ (To-Do List) — программа на Python с окном и консолью
=================================================================

ОПИСАНИЕ
--------
Программа для планирования задач: учёба, работа, дом, личные дела.
Позволяет добавлять, редактировать, удалять и отмечать задачи выполненными,
искать и фильтровать их, сортировать, смотреть статистику и просроченные
задачи, а также сохранять/выгружать данные в файлы.

Есть два режима:
- окно (по умолчанию) - сделано на PyQt6, внешний вид нарисован в Qt Designer
- консоль (старое меню из 14 пунктов) - python main.py --konsol
Если PyQt6 не установлена, программа сама запускается в консоли.

КАК ЗАПУСТИТЬ
-------------
Вариант 1 - готовый файл (питон не нужен вообще):
   запустить SpisokDel.exe (Windows), SpisokDel.app (macOS) или SpisokDel (Linux).
   Все библиотеки уже внутри файла. Задачи сохраняются в zadachi.json рядом с ним.
   На маке при первом запуске: правый клик -> Открыть (программа не подписана).

Вариант 2 - из исходников:
1. Установите Python 3 (можно запускать прямо из IDLE).
2. Установите библиотеки:
       pip install PyQt6 colorama
   (colorama нужна только для цвета в консольном режиме, без нее тоже работает)
3. Откройте main.py в IDLE и нажмите F5, либо запустите из терминала:
       python main.py            - окно
       python main.py --konsol   - консоль

КАК СОБРАТЬ ОДИН ФАЙЛ ДЛЯ ЗАПУСКА
---------------------------------
       pip install PyQt6 pyinstaller
       python sobrat.py
Готовый файл будет в папке dist. PyInstaller собирает только под ту систему,
на которой запущен, поэтому в репозитории есть .github/workflows/sborka.yml -
GitHub сам собирает версии для Windows, macOS и Linux (вкладка Actions ->
последний запуск -> внизу Artifacts).

КАК МЕНЯТЬ ОКНО (без программирования)
--------------------------------------
Внешний вид окна НЕ написан руками, он нарисован мышкой в Qt Designer
и хранится в файле forma.ui.
1. Установить дизайнер:  pip install pyside6   и запустить командой  pyside6-designer
   (или скачать отдельную программу Qt Designer для Windows/macOS)
2. Открыть в нем forma.ui, двигать/добавлять кнопки и поля, сохранить.
3. Превратить рисунок в питон-код:
       pyuic6 forma.ui -o forma_ui.py
   (sobrat.py делает это сам перед сборкой)
4. Если добавили НОВУЮ кнопку - подключить ее к функции в gui.py,
   в функции podklyuchit_knopki(), например:
       ui.knopkaNovaya.clicked.connect(moya_funkciya)
   Имя кнопки (objectName) видно в дизайнере справа, в панели свойств.
Важно: имена уже существующих элементов (knopkaDobavit, tableZadachi и т.д.)
лучше не переименовывать - по ним gui.py находит нужные кнопки.

СТРУКТУРА ПРОЕКТА (модульность)
--------------------------------
- main.py       — точка входа: запускает окно или консольное меню
- gui.py        — логика окна: подключает кнопки к функциям
- forma.ui      — внешний вид окна (файл Qt Designer)
- forma_ui.py   — код окна, сделанный из forma.ui командой pyuic6 (руками не править)
- zadachi.py    — вся логика работы с задачами (добавление, поиск,
                   сортировка, статистика и т.д.) + консольные функции
- fayly.py      — сохранение/загрузка задач (JSON), экспорт в txt,
                   резервное копирование
- helpers.py    — вспомогательные функции для консоли: проверка ввода,
                   печать меню, цветной вывод
- constants.py  — настройки и списки (категории, приоритеты, имена файлов)
- sobrat.py     — сборка программы в один исполняемый файл
- zadachi.json  — файл с задачами, создаётся автоматически при первом
                   запуске
- backup/       — папка с резервными копиями (создаётся при первом
                   использовании пункта "Резервная копия")

БЕЗ БАЗЫ ДАННЫХ И БЕЗ КЛАССОВ
-----------------------------
Все задачи хранятся как обычные списки словарей (list of dict) в обычный JSON-файл.
Свои классы в программе не используются. Единственный класс - Ui_GlavnoeOkno
в forma_ui.py, но его генерирует pyuic6 автоматически из forma.ui.

ОСНОВНЫЕ ВОЗМОЖНОСТИ (функции)          ГДЕ В ОКНЕ
-------------------------------          ----------
1. Добавление задачи                     форма справа -> "Добавить новую"
2. Просмотр всех задач / одной задачи    таблица слева, клик по строке
3. Редактирование задачи                 клик по строке -> правка -> "Сохранить изменения"
4. Удаление задачи                       кнопка "Удалить"
5. Отметка "выполнено"/"не выполнено"    кнопка "Выполнено" / "Вернуть в работу"
6. Поиск по названию и описанию          поле поиска сверху
7. Фильтр по категории                   список "Все категории" сверху
8. Сортировка                            список сортировки сверху
9. Статистика по задачам                 кнопка "Статистика" + строка внизу окна
10. Просмотр просроченных задач          фильтр "Просроченные" (меню Задачи), срок красным
11. Экспорт списка задач в txt           кнопка "Экспорт в txt" / меню Файл
12. Резервное копирование данных         кнопка "Резервная копия" / меню Файл
